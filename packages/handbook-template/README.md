# 知识手册阅读模板

Git 管理的空白手册框架，版本为 `handbook@1.0.0`。布局与视觉参数从用户原有手册的阅读框架提取并适配：左侧分类目录、顶部分类切换、阅读总览、单篇文章、上下篇、全文搜索和打印。项目标题、分类、文章及资源全部由宿主注入；模板默认无文章、分类、向量、密钥、缓存或历史记录，不包含原项目资料，也不执行原手册脚本。

`src/index.ts` 提供模板清单、配置归一化、按可见修订过滤的目录、包内翻篇、章节和搜索片段辅助函数。`skin.css` 保存共享主题参数，`framework.css` 保存 `.vks-handbook .hb-*` 框架样式。在线 React 适配器为 `apps/studio/src/HandbookTemplate.tsx`，正文继续使用平台共用 Markdown 渲染器，支持图片、表格、公式及图表。

宿主须先做项目、权限和版本过滤，再注入准确修订。模板对注入目录再次按提供的可见文章集合过滤。全文搜索优先委托宿主的授权索引接口，不预先下载全文；独立宿主未提供搜索接口时才按需并发读取当前可见文章。缓存只存在组件会话中，切换基线时清空。文章不因阅读模板改变而生成新正文或改写原始字节。

AI 和更新按钮分别委托 `onAskAI` / `onUpdate`，嵌入平台时使用平台的助手和资料导入、版本保存、建库、关联迁移流程。只读宿主传 `readOnly=true`，不会显示文档更新入口；个人 AI 连接仍由宿主管理，模板自身不接收或保存凭据。

模板兼容普通 MD、HTML 索引正文和其他平台支持的资料格式。原样文档是独立阅读方式；此模板不会自动宣称任意原始 HTML 的脚本或独有能力均已移植。

离线导出共用 `src/skin.css` 和 `src/framework.css`；`src/offline.css` 只补充导出宿主的适配规则。`node scripts/reader_handbook.mjs` 生成 API 内嵌样式资产，`--check` 只验证是否同步；完整 reader 构建会自动重新生成。`reader_assets/handbook.js` 把平台已授权的目录和 Markdown 节点装配到同一框架，保留准确章节定位、本地搜索、图片与图表，以及平台的外层 AI 助手。导出的只读框架不显示导入或编辑操作。

资料管理中的“下载手册模板（可选）”由 `handbook_authoring.template_html()` 构建空白可编辑 HTML。下载后可本地导入 MD、TXT 和栅格图片，也可选择目录保留内部层级；同路径文件更新替换，支持编辑和删除，再保存为可继续编辑的 HTML。保存从固定平台框架重建，不序列化当前页面 DOM、个人 AI 连接或聊天记录。个人 Key 始终只在当前页面内存中。

保存文件的惰性 `vks-template-data` JSON 使用 `vks-handbook-authoring-1` 信封，仅包含模板 ID、版本、普通 Markdown 和图片。平台重导时把这些内容交回普通文档、附件、版本和 RAG 流程；原始 HTML 仍完整保留。图片支持 PNG、JPEG、GIF、WebP，单张最多 12 MiB 和 16,777,216 像素；单文档 2 MiB、正文与图片合计 64 MiB，最终 HTML 最多 80 MiB。可编辑模板和只读成品使用不同标志与入口，只读成品不会获得本地作者能力。
