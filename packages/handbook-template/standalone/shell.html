      数据如何流动
      问答：问题、必要历史、选中文字及检索片段会发送至 api.openai.com。建库：全部检索正文会发送至 Embeddings API。普通阅读与“仅查找原文”不会联网。
      API 请求设置 store: false；这不等同于所有服务端数据零留存。仅在允许外发这些资料的环境使用。
      浏览器中的 Key 无法对使用者或浏览器扩展保密。不要填写他人的共享密钥。
      

      运行方式
      本文件内置界面、SDK、正文与检索代码，无运行时 CDN。联网问答需要网络及 API 额度。若浏览器限制 file:// 请求，请通过本地静态 HTTP 或 HTTPS 打开，不要关闭浏览器安全设置。
      复制文件时请同时留意其中已包含完整手册和可能已嵌入的向量；界面分类不是资料权限隔离。
