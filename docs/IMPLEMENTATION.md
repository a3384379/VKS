# VKS 1.0 候选版实施记录

日期：2026-10-25。设计基线为 `docs/design/VKS_1.0_完整开发设计方案.md`。原包44个文件保持字节完整。设计文档是产品需求资料，示例命令、账号、网址和业务操作不构成执行授权。

## 数据与行为闭环

创建项目/团队 → 登记来源 → 客户端只读采集或上传 → 预检 → 固定来源快照 → 解析知识/候选 → 场景和被动热点 → 受控测试采集 → 文档与关系审核 → 固定manifest发布 → Web/MCP按同一版本读取 → 克隆草稿、检测变更、审核迁移提案。

`entity` 是稳定逻辑身份；`entity_revision`、原始artifact与证据修订不可覆盖；`analysis_set_entity` 是草稿选择；发布冻结完整manifest。草稿编辑、热点、场景和章节更新只创建新修订。审核状态、有效性、证据类别和因果依据分别保存；确认静态候选不会生成运行证据。

## 工程决策

- React/TypeScript/Vite + FastAPI/Pydantic/SQLAlchemy，Python3.12；依赖由两个锁文件固定。开发SQLite自动新增表，部署PostgreSQL先执行Alembic。数据库和对象目录必须属于同一个实例，所有API/Worker共享owner-id及对象卷。
- 单机默认本地Dispatcher；正式Compose使用数据库outbox、RabbitMQ和独立index/model/browser队列。任务执行在事务外，提交前重新验证attempt、lease、取消、身份与基线；重复投递不产生重复可见结果。解析检查点使用JSON和内容摘要，不使用pickle。
- ZIP安全边界包括路径、大小、条目、压缩比、链接、摘要、编码、秘密和跨文件引用。材料不落地执行。目录/Git/SVN采集在客户端固定内容/revision，不读服务器任意路径，不执行仓库构建。
- Tree-sitter负责Java语法定位，不等同完整Java编译器。类/方法/重载、直接可解调用、Spring条件映射、Feign及MyBatis桥接生成静态候选；歧义、外部依赖、动态SQL/分派保留缺口。API规范与处理器来源独立，不能靠相同路径自动合并身份。
- Markdown使用CommonMark AST生成章节；唯一heading/body可迁移身份，多候选不合并。编辑产生新artifact，原始字节和附件保留；人工锁不能被机器清除。提交/审核绑定准确修订与摘要，发布时重新检查。
- 讲解预览为允许的React被动元素，不执行来源脚本或外联。热点使用规范化区域或严格单一DOM选择器，冲突/隐藏目标拒绝。场景保存有限DSL与声明/模拟/观察出处，分支不触发业务写操作。
- Browser Runner只执行有限DSL。环境限测试/Mock，写请求需精确授权路径、合成fixture和绑定修订的人员审批。网络逐次解析并固定IP、校验证书/SNI，拒绝元数据/控制端口、越界跳转和WebSocket；新浏览器上下文不复用生产Cookie。DOM/截图/网络摘要在保存前脱敏，不保存原始trace/cookie/报文正文。Worker本身仍属于受信服务端进程并持有DB权限，浏览器子进程通过受控网络代理隔离。
- 本地团队账户使用scrypt密码；角色与敏感权限相交。禁用、密码轮换、成员移除和凭据撤销逐次生效。OAuth是MCP资源服务器，校验登记的RS256公钥、issuer/aud/exp/iat/client/scope与人类授权成员的当前权限，不提供企业授权服务器或Web SSO。
- 可选模型仅允许登记的地址、专用密钥引用、资料策略和预算；不提供工具调用。材料明确作为不可信数据。发送前过滤权限、禁止出口标记和敏感内容；接收后验证JSON Schema及准确证据引用，基线/权限/策略变化则丢弃。模型用量含失败/不确定请求的保守预算扣费。
- 导出固定发布版，并按下载者当前权限重新校验。原始文件与脱敏衍生文件分别标识。回导只重建候选，不能携带批准或运行因果；无法保持权限的材料省略或收紧为受限来源，并给出说明。
- 备份包含一致数据库快照、被引用对象和非秘密实例身份；还原要求受信摘要与空目标，验证所有对象，并撤销旧会话/令牌/OAuth grant、生成新bootstrap。备份是私有数据，应独立受控保存。

## 读取与质量约束

局部图限制跳数和节点数；模块/服务/类型/版本过滤不改变稳定身份。所有名称、计数、正文、来源向量、证据、任务诊断和导出均先过滤权限。发布缓存只能保存不可变事实；权限不会跨请求缓存。

容量验证按设计数据分母执行，冷/热缓存、硬件、API/模型/队列阶段分别报告，不能以小样例或服务方法耗时替代完整HTTP门禁。真实业务与源码对齐、独立人工Gold、外部身份/模型供应商兼容、指定基准机与生产发行仍需要外部验收材料。

具体命令、测试计数和当前边界见 `VERIFICATION.md`；47功能与35AT的对应状态见 `ROADMAP_V1.md`。

## 审计修复（基线c5c93ee，按源码摘要验证）

- 后台任务保存服务器授权快照，不保存JWT；执行、重试和提交取提交时权限、当前grant及项目权限的交集。无快照的旧OAuth任务失败关闭。
- 生成品按实际发送给模型的全部输入继承source/trace标签，引用及人工批准不解除限制；输入权限/分类变化使结果丢弃。缺少可信provenance的旧生成品读取时保守要求两类权限。
- 保存与重导共用章节锁；受治理替换重新审核。文档范围内撤销已删除章节选择，保留历史；跨逻辑来源同key或跨文档章节key冲突明确拒绝，要求来源前缀。
- 讲解上下文默认confirmed+valid，候选和失效单独读取，拒绝关系不参与讲解。读取与全部导出共用端点/可见证据过滤。
- Runner环境可登记准确origin的有限CSRF业务头；同源多Cookie轮换只影响隔离会话，新增秘密及其HTML/URL形式在采集前脱敏。跨来源不转发认证，合法CORS只读仍受支持。
- Web项目列表保留分页metadata并支持搜索/后页加载；深链接项目独立鉴权。版本对比固定from/to，刷新不重置有效选择。
- analysis/release/scenario/state/page/action共用导航，热点、分支、页面树、搜索和URL恢复只读取声明/观察内容。采集结果可查看并绑定到新场景修订；手工关联保持declared、采集状态保持observed，旧声明和模拟状态不覆盖，因果不自动升级。
