# 使用 ChatGPT 订阅问答

## 本机 Studio

1. 通过本机 Studio 启动器启动个人模式。在项目的「AI 设置 → 模型连接」找到「ChatGPT 订阅」，点击「使用 ChatGPT 登录」。
2. 在系统浏览器中选择自己的 ChatGPT 账号，允许 VKS 使用 ChatGPT 额度。回 Studio 读取可用模型，选择模型并允许发送必要的项目片段，再点「本页使用 ChatGPT 额度」。
3. 用现有「回答」和单条「AI 讲解」提问。当前页选用订阅时，输入框上方会标明用量来源。可在设置中切回项目模型。会话到期、撤销授权或达到用量限制时，检索及原文阅读继续可用。
4. 手动启动 API 时，订阅入口要求个人模式、绑定回环地址、配置 `VKS_STUDIO_BASE_URL` 并设置 `VKS_CHATGPT_LOCAL=1`。入口面向用户控制的 macOS 和 Windows 本机运行时。

ChatGPT 连接与 Studio 登录各自管理。连接器和同机 Studio 在相同的本机配置目录下共用选定账号。用户可在 ChatGPT 设置查看额度、应用限制和撤销授权。 [OpenAI 资格与用量说明](https://help.openai.com/en/articles/20001542-using-your-chatgpt-plan-in-other-apps-and-sites) · [OpenAI 接入条款](https://openai.com/policies/sign-in-with-chatgpt-terms/)

## 生成和打开成品库

1. 在 Studio 的「资料管理」导出成品库。HTML 继续包含当前保存版本的原文、图片、原型、已有的关联和本地向量。导出过程只做本地处理。新版导出还记录可供订阅问答使用的章节范围。
2. 接收者可直接双击 HTML，离线阅读和搜索。需要按意思搜或使用 ChatGPT 订阅问答时，解压当前平台的 VKS 连接器，在 Windows 双击 `Open VKS Library.cmd`，在 macOS 双击 `Open VKS Library.command`，然后选择这个 HTML。也可运行 `vks-connect library open <HTML 路径>`。
3. 阅读器可用包内向量按意思搜，向量不可用时使用关键词。登录自己的 ChatGPT 账号、选择模型并设置外发许可后，点击「用 ChatGPT 回答」。点击引用可先预览原文章节，再在原 HTML 内定位。读取旧导出时，离线搜索和预览仍可用。启用订阅问答需要用支持该功能的 Studio 重新导出。
4. 结束后关闭终端窗口或按 Ctrl+C。macOS 将订阅凭据存入仅当前用户可访问的 VKS 本机目录，Windows 使用系统密钥库。导出文件只携带资料和章节范围，接收者的登录和用量单独管理。

## Codex 左栏

在左栏 VKS 选择成品库并输入问题，回车或点「AI 分析」。首次打开「ChatGPT 订阅设置」时，登录自己的账号或继续使用同机已有的 VKS ChatGPT 连接，选择模型并授权发送必要片段。结果区显示分析和章节引用，点击引用才读取并打开原文预览。

macOS 从使用钥匙串的旧版升级后，在「ChatGPT 订阅设置」里用浏览器授权一次。之后打开 Studio、插件或成品库阅读器使用同机连接时，无需输入钥匙串密码。

「本地检索」可在断网或未登录时使用，结果显示章节标题和所属文档。点击标题预览同一章节。旧导出可以继续本地检索，AI 分析需要使用新版 Studio 导出的成品库。

## 验收

- 真实项目只使用**当前保存版本已收录并生效的文档内容**。云收费以「收费标准公式」和「月卡首次开通」为例，分别在 Studio 和成品库阅读器核对引用与定位。
- 比较新导出里的原文、图片、章节定位和关联。验证重复导出复用已生成文件，新版本重用未变化章节的向量。
- 未登录及断网时验证本地关键词和向量检索。登录后的真实验收要求合资格的本人账号完成授权，成功获得一条完整回答，再确认有效的章节引用和官方用量记录。
- macOS 和 Windows 分别验证文件选择器、浏览器授权回跳、原文件链接和退出后降级。构建与合成验证结果须与真人授权结果分别记录。

本次在云收费 v24 隔离副本中重新导出。245 份文档、6,690 个章节、257 条已有关系及 13,679 个向量片段与旧导出一致。首次生成新版 HTML 和重复导出均复用了原有向量，重复导出的 HTML 与首次生成字节一致。macOS 原生阅读器在隔离 Chromium 中通过旧版和新版 v24 的两项业务查询、原文章节预览及定位检查。

OAuth 授权、续期、撤销、订阅请求和引用过滤已用合成服务验证。macOS 插件 3.1.0-rc.13 使用已有 ChatGPT 授权和 GPT-6-Luna，针对云收费 v24 的「收费项和收费标准有什么区别」收到完整回答，三个引用均可通过左栏的章节预览工具读取并匹配成品库原文锚点。服务响应可以省略 `Content-Type`。连接器读取事件流，并在收到 `response.completed` 后才采用完整回答。官方用量记录和 Windows 实机体验待现场验收。
