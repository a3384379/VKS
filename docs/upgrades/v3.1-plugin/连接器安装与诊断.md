# VKS 3.1 连接器

Codex 插件包提供左栏面板、需求分析 Skill 和 VKS 连接器。默认直接读取用户选择的 VKS 只读成品库 HTML，使用本机的文件路径和导出快照。换电脑时把同一份成品库文件复制过去，安装相应平台的插件并选择它即可。成品库携带原文、原型、已保存关联、引用和检索数据。MCP 服务由插件内的连接器启动。

## 成品库模式

使用 ChatGPT 订阅问答请按[本机 Studio 与成品库阅读器说明](chatgpt-plan.md)操作。

Windows x64 的下载、安装命令和试用步骤见 [Windows 安装与试用](windows-codex.md)。

1. 校验并解压对应平台的插件包。把该目录加入本地插件市场并安装 VKS，再重开 Codex。
2. 在 Codex 左栏点击 VKS 和「选择成品库」，选择 Studio 导出的只读成品库 HTML。选定后页面显示项目、保存版本和文件名。路径由连接器保存在当前用户的配置目录。可随时点「更换成品库」。
3. 在面板搜索后，点结果标题或「预览原文章节」即可在 Codex 内查看原文和包内图片。预览底部的「在成品库打开原文章节」进入同一个 HTML 文件并定位到对应章节。也可在 Codex 对话中用成品库 MCP 工具搜索、读取章节和核对已有的关联。关键词检索、读取及定位均使用本地文件，无需起 Studio、VKS API 或填写令牌。

选择离线向量版成品库后，左栏默认在本机按语义和关键词混合搜索，无需 API Key。模型随原生插件包安装。旧成品库或本地模型不可用时，面板会显示关键词检索及原因。

Studio 的「资料管理 → 导出当前成品库」默认生成带本地向量的 HTML，并固定当前草稿到新的保存版本。也可以在完整版本列表用「导出 HTML」导出已有版本。新安装使用 `make install` 准备本地模型。若源码工作区已有依赖但缺少模型文件，运行 `python scripts/fetch_vks_local_model.py` 补齐；API 镜像已在构建时准备模型。

如需沿用已有的云端向量，展开「云端向量检索（可选）」并选中对应选项。旧配置可直接使用，也可填写兼容的嵌入服务地址并在系统窗口输入 Key。只有选择云端检索时才会向已配置的嵌入服务发送查询词。

在有源码的电脑上，可给已有成品库生成离线版。该步骤使用本机 CPU，输出独立 HTML，并可选附上 Markdown 需求。

```sh
python scripts/fetch_vks_local_model.py
uv run --frozen --with-requirements packages/vks-connect/offline.lock.txt \
  python scripts/export_offline_library.py 原成品库.html --output 离线成品库.html \
  --supplement 新需求.md
```

文件选择器遇到桌面限制时，可在终端执行 `vks-connect library use <成品库 HTML 路径>`。`vks-connect library status` 显示当前快照版本和文件指纹。同一个文件副本保留相同的关联和原文引用。

## API 接入

需要访问一套在线的 VKS 实例时，使用下列 API 连接方式。API 左栏模式的本机连接器启动参数为 `mcp --codex-sidebar`。

1. 校验发行包 SHA-256，解压到独立目录。保留 `bin` 下的所有文件。发行包内的 `build-info.json` 记录版本、架构和签名状态。
2. 在终端以连接器的绝对路径调用工具。下列命令中替换程序路径和端口。Windows 在程序名后加 `.exe`，PowerShell 用 `&` 调用引号内的路径。

   ```text
   /absolute/path/bin/vks-connect configure --api-url http://127.0.0.1:8014 --studio-url http://127.0.0.1:5193 --runtime-url http://127.0.0.1:5195
   /absolute/path/bin/vks-connect auth set
   /absolute/path/bin/vks-connect doctor
   ```

3. `auth set` 从终端无回显读取令牌，凭据保存在当前用户的 macOS Keychain 或 Windows Credential Manager。无法使用系统密钥库的环境可为当前连接器进程提供 `VKS_CONNECT_TOKEN`。不要在命令参数、配置、包或日志里保留令牌。凭据按连接配置路径、类型和地址区分。永久更换地址前可移除旧地址对应的凭据。
4. 选择一种接入方式。插件模式使用包内 `plugin.json` 和 `mcp.json`，按 Codex 本地 marketplace 指引安装。纯 MCP 模式使用 `codex-config --dry-run --command <绝对程序路径>` 生成配置。需要检查现有配置时，可用 `config-diff --existing <现有 TOML> --command <绝对程序路径>`。确认差异后只合并 `mcp_servers.vks`，避免与插件的服务器重复注册。连接器命令不会写 Codex 配置。
5. `doctor` 检查 API/Studio 实例标识、Runtime 就绪和只读访问。可在 `configure` 加 `--default-project-id <UUID>` 以核对该项目最新可读保存版本。Runtime 是否完成登记与准确定位需通过浏览器确认。

配置目录分别是 macOS 的 `~/Library/Application Support/VKS/connector` 与 Windows 的 `%LOCALAPPDATA%/VKS/connector`。每个命名连接可独立配置。Windows 需要可验证 ACL 的本机文件系统；企业重定向目录、网络盘与超长路径应单独验证。

在支持全局 MCP App 入口的 Codex 桌面端，插件可以从左栏打开 VKS 搜索面板。搜索结果进入视口后读取该保存版本的完整章节，显示 Markdown、Mermaid 和已授权的 PNG、JPEG、GIF、WebP 附件，每张附件最多 2 MiB。完整章节及附件可通过 Studio 阅读。点击 Studio 链接由系统默认浏览器打开，也可复制地址。重新打开桌面客户端可加载新版入口。若 macOS 在本机临时签名包升级后询问旧钥匙串条目的访问权限，可为当前安装的连接器使用独立命名连接和同范围的专用令牌。

## 启动仓库里的 VKS Studio

在 VKS 仓库使用 Python 3.12 环境及锁定的 Node 依赖。运行 `uv sync --frozen` 和 `npm ci` 后，使用以下入口启动同一份 API、Studio 与 Runtime。

- macOS 使用 `./scripts/start-studio.sh`。
- Windows 在 PowerShell 中运行 `.\scripts\start-studio.ps1`。

可指定 `--data-dir`、`--studio-port`、`--api-port`、`--runtime-port` 和 `--node`。默认监听本机地址。启动器发现端口占用时会退出并显示端口号。用于试验时请显式传入隔离的数据目录。开发启动与薄连接器独立，连接器可使用已经运行的兼容 VKS 实例。

仓库的 Studio 启动入口可从 `.vks/studio-preview/data-directory` 读取一行本机数据目录绝对路径。显式 `--data-dir` 或 `VKS_DATA_DIR` 优先。迁移数据目录后可用该文件固化本机选择。

macOS 上，Runtime 来源密钥与持久化模型凭据要求文件归当前用户所有、权限私有，且所在卷启用了所有权检查。对启用「忽略此宗卷的所有权」的外置卷，这两类文件的读写会被拒绝。可以将 `VKS_RUNTIME_DATA_DIR` 指向启用所有权的专用目录，供当前实例的 Runtime 单独存放来源密钥。默认模型的密钥也可通过 API 进程的 `VKS_MODEL_API_KEY` 注入。需要保存模型凭据时，使用启用所有权的实例数据目录。[Apple 文件系统权限说明](https://developer.apple.com/library/archive/documentation/FileManagement/Conceptual/FileSystemProgrammingGuide/FileSystemDetails/FileSystemDetails.html)

## HTTP MCP

用 `configure --runtime-mode documents-only --api-url <API 的 HTTPS 地址> --studio-url <Studio 的 HTTPS 地址> --mcp-url <只读 MCP 的 HTTPS 地址>` 保存地址。仅同机 loopback 可用 HTTP。用 `auth set --target mcp` 登记用于诊断的凭据，随后运行 `doctor --transport http` 核实服务端暴露的是只读工具和同一实例。客户端已配置 OAuth 时，可使用 `codex-config --transport http --dry-run`。当前会话 bearer 模式加 `--session`，由宿主环境提供 `VKS_CONNECT_MCP_TOKEN`。桌面应用从 GUI 启动时，不能假定会继承终端环境变量。关闭 HTTPS 校验或跟随重定向可能泄露令牌。

## 升级、移除与数据恢复

验证新包摘要后解压到新目录。切换插件路径或单个 MCP 配置项，再运行 `doctor`。诊断失败时可切回旧包路径。移除时先停用对应插件或删除单个 MCP 配置项，再按需运行 `auth remove` 或 `auth remove --target mcp` 清理当前连接凭据，最后移除程序目录。相关的 `.vks`、其他配置和独立连接由用户保留。

VKS 私有备份中的 `rag-state.json` 保存 `rag-vectors.sqlite` 的项目设置与嵌入用量账本。恢复后重新构建向量索引，查询嵌入缓存和索引状态可重建。私有备份与凭据独立管理。
