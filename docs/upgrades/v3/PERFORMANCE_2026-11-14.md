# Studio 读取与启动性能复查 · 2026-11-14

本轮基线为 `fb0b955`，继续检查上一轮审计后仍偏慢的实际读取路径。保持原始 HTML 字节、当前准确版本和逐次权限检查，没有新增依赖、数据库结构或真实付费模型调用。

## 发现与修改

| 瓶颈 | 原因 | 本轮修改 |
| --- | --- | --- |
| 打开原文仍要等其他资料 | 未访问的原型和手册同时挂载；目录等待关联清单一起返回 | 首次访问才挂载对应原始页面，之后保留 iframe 与表单；目录就绪即开始阅读，关联异步补齐 |
| 目录、关联与原样定位反复读取正文 | 目录也将约 5,800 个修订和实体装入 ORM，单次约 8.34 MB 正文；包校验反复加载章节 | 按实体种类和关联端点取数；完整来源权限下使用精确身份、归属与映射投影，保留受限读者和旧映射的原验证路径 |
| 包成员查询重复扫描 | SQLite 对“项目 + 多个修订 ID”选用项目索引，每个批次重复扫描；同次请求多次解析成员 | 按准确主键查询，返回前校验项目与类型；只在同一只读事务复用不可变成员、包根及修订事实 |
| AI 本地检索重复准备 | prepare、binding、semantic 重复打开读取范围；词法评分扫描全部片段并重复转换正文 | 同阶段共用读取快照，使用紧凑倒排表计算相同 BM25 分数；跨模型调用仍重新验证权限、输入及排除状态 |
| 获取原型顺带检查手册 | 原始内容请求先列出并校验全部包 | 先按目标制品过滤，再完整验证目标包；不扫描未请求的手册章节 |

包、修订缓存含当前 Actor / 项目 / 准确选择与过滤条件；退出读取事务后释放。包成员缓存只保存身份事实，不能代替权限判定；写事务不复用这些缓存。完整来源和 trace 权限的快速路径仍验证项目、实体、制品、准确章节选择和证据归属。

交叉审计还复现了“目录先返回、关联仍在途时手动编辑误认新关联”的窗口：保存被版本冲突拒绝，原人工说明没有被覆盖。现将手动编辑的开放时点绑定到关联读取完成，阅读不等待关联。

## 本机测量

真实资料为 204 篇文档、5,476 个章节。原型为 **11,475,665 字节**，手册为 **28,528,347 字节**，两者均为原始资料。直接打开文档只下载手册，减少约 **11.5 MB / 28.7%** 的原始内容；直接打开原型则不下载手册。访问另一视图后才补载，往返不重复创建原始页面。

HTTP 表使用同一台机器、同一资料、同一完整来源权限账户。GET 各采样 4 次，本地 related 采样 3 次；包含各组首次请求，报告中位数。修复前取上一轮最终空闲样本，修复后取本轮最终空闲样本。不是并发负载测试、受限账户测量或跨机器时延承诺。

| HTTP 路径 | 修复前中位数 | 修复后中位数 |
| --- | ---: | ---: |
| 目录 catalog | 483.4 ms | 137.5 ms |
| 关联清单 bindings | 373.2 ms | 32.2 ms |
| 原样文档定位 native | 375.5 ms | 90.5 ms |
| 本地相关章节 related | 779.3 ms | 321.4 ms |

独立词法检索样本中，BM25 搜索中位 **20.71 → 2.98 ms**，结果与穷举参考实现逐项比对一致。tracemalloc 测得索引新增常驻内存约 **73.4 → 30.3 MB**，这是索引增量，不能当作整个服务进程内存。无 tracemalloc 的首次索引构造约 **246 → 268 ms**：紧凑索引多付出约 22 ms 首建成本，换取后续搜索与内存收益。

## 后续反馈：导出阅读器

同轮收到导出 HTML 的设置和阅读导航反馈，修改平台独立阅读器，原始资料继续保持不变。

- 模型选择改为一个原生下拉框，选择服务返回的准确 ID，或明确切换到自定义输入。移除 datalist 与额外下拉叠加，适配触控、320px 和横屏。
- 助手页签使用独占选中态与键盘导航，头尾固定，内容单独滚动；局部更新模型目录时保留焦点、滚动和连接状态提示。
- 更换协议、服务地址、服务商或 Key 后使旧目录失效，取消旧请求并拒绝迟到结果；切换页签后仍正确显示目录加载状态。密钥只保存在页面内存，刷新后清除。
- 补齐文章页尾的上一篇、下一篇，沿当前资料包的分类树顺序翻篇，跨分类同步目录，首尾省略缺失方向；不跨资料包串入其他文章。
- 增加独立 AI 讲解页签及右键入口，主动生成才联网。已有说明按准确目标离线展示并标注来源；新讲解与问答历史分开，按包、路由、frame、selector、state、label、scope 等上下文隔离，切目标或进入文档页停止旧讲解。检索后、流式回包时验证取消状态，复用引用及 2 MiB 响应限制。
- 本地自动匹配原先直接显示折叠后的 160 字原始 Markdown，造成标题、粗体和反引号露出。现与正文、问答共用安全渲染器，按准确文档解析相对图片和链接，保留完整章节及引用定义，预览以 CSS 限高并可展开，不再切断 Markdown 语法。
