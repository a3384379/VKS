# VKS 3.0 开发记录

开发分支为 `codex/vks-3.0`，基线为 `2ec30d95399ae003384b1dad2a717a18750f4f02`。本批按 [D1 方案](VKS_3.0_完整产品与技术方案.md)的 M1 范围建立原样导览。验证结果见[验证记录](VERIFICATION.md)。

## M1 原样导览

- 现有 VKS 资料包增加 `prototypeManifest` 侧车。当前每份清单接入一个页面，最多 32 个状态。每个状态记录视口、DPR、归一化热区及可选 PNG 原图。预检校验 PNG 实际类型、尺寸、摘要、同来源归属和热区冲突，并报告待补画面的状态。
- 页面和动作沿用现有稳定身份与不可变修订。页面、动作和 PNG 分别保存在现有实体、制品和对象目录。快照沿选中的页面修订读取原图，图像请求同时校验项目、版本、页面修订、状态和当前访问范围。画面限制会传递给依赖该图的页面及动作。无数据库结构变更。
- Web 的「页面与状态」入口显示原尺寸或等比适宽画布。热区可隐藏，动作也可以用键盘从列表选择。目标状态有图时切换，缺图时留在触发画面。地址保存显示状态和触发状态，原文往返继续使用现有文档阅读器。
- 说明使用同版、有效且有可见证据的现有 `documents` 关系，直接显示章节摘录。跨状态的同名操作如有不同含义，清单为其声明不同动作 key。独立业务点、反查和热区维护进入 M3。可回导知识包对包含栅格原型的版本返回明确错误。原始资料包和实例备份仍是本批原图的迁移载体。

## 在隔离项目试用

1. 创建项目，填写项目标识 `prototype-demo`。也可将下面的 `--project` 改为隔离项目的实际标识。
2. 生成合成资料包。

   ```sh
   uv run python scripts/build_prototype_demo.py /tmp/vks-prototype-demo.vksbundle.zip --project prototype-demo
   ```

3. 在项目的「智能接入」向导进入资料导入步骤，选择「VKS 资料包」，上传、预检并确认导入。
4. 打开「页面与状态」，选用 `prototype-v1` 草稿。试用新增收费项、同步月卡套餐、编辑后的违约金设置及导出。若需向只读账号开放，可用现有「保存快照」固定版本。

## 真实云收费试点

已从工作区外的云收费原型合集和知识手册 HTML 静态读取数据。手册包内 204 份原文摘要全部吻合，三组试点章节各有一个标题定位。

| 同步月卡套餐 | 《manage 管理中心业务说明》「17.3 停车月卡配置」 | 1301 |
| 违约金设置 | 《账单违约金计算豁免与调整操作手册》「1. 先问客户想改什么，再找对应入口」 | 5 |

原型包内的 102 条路由含 `/chargeItemMgnt`，对应页依赖脚本。94 个 PNG 资源中，尺寸至少 1000 × 600 的四个是催缴通知素材和页面背景。当前尚缺可绑定准确视口与状态的收费项管理列表、新增和编辑截图，以及违约金设置和可用的月卡同步画面。上述章节行号是 M0 取证定位，原型状态与业务规则的实际对应关系仍待核定。合成试用资料与业务资料分开。云收费 HTML 适配及全量接入属于 M2。
