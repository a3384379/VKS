## 试用

1. 运行 `make install` 和 `make dev`。已有实例升级步骤见[安装、升级与回退](RELEASE.md)。
2. 创建项目，填写项目标识 `prototype-demo`。用下列命令生成可分享的合成资料包。也可用 `--project` 指定实际项目标识。

   ```sh
   uv run python scripts/build_prototype_demo.py /tmp/vks-prototype-demo.vksbundle.zip --project prototype-demo
   ```

3. 在项目的「维护 → 智能接入」选择「VKS 资料包」，预检并确认导入。打开「原型导览」，选用 `prototype-v1` 草稿。
4. 在列表试用新增收费项、同步月卡套餐、导出，或进入编辑画面后选择违约金设置。编辑需要相应权限。使用「保存快照」固定当前版本。

## D2 单文件只读成品库 · 2026-11-13

新增 `readonly_html` 导出格式，Web / MCP 共用快照、任务与下载服务。Studio 可导出当前组合或指定完整版本；当前组合先保存独立快照，工作区保持可编辑。后台准备阶段读取准确原型闭包、平台章节、有效关联和讲解，补齐选定章节的真实向量，再生成 gzip 内嵌数据与无外部依赖阅读器。最终提交和下载均复核权限及准确输入，网络调用在知识库事务之外进行。

普通 Markdown 的建库独立于原型：文档导入、替换后通过持久化任务自动索引，只有文档的项目也可建库和导出。任务逐批检查取消、执行资格、资料组合和模型配置；既有模块查询预热保留。Markdown ZIP 的栅格附件按不可变包版本保存，导出按已选版本解析，正文未变但图片更新时不会误用旧图。

阅读器统一提供原型演示、安全 Markdown、离线搜索、文档与原型双向定位、已有讲解和浮动助手。采用独立不透明来源运行原型，不向材料发送密钥。使用者在阅读器内自行填写模型连接与 API Key，默认只保留本次页面内存；支持模型列表、Responses / Chat Completions 流式回答及可选相同嵌入模型检索。没有网络或密钥仍可阅读与检索，新的生成式回答需要联网。

成品不复制原始手册的 AI、向量库或特有功能；不提供知识编辑、资料更换、版本维护或业务写入入口。具体入口、兼容边界与使用说明见 [单文件只读成品库](READONLY_LIBRARY.md)。本轮实现及合成/真实模型验证不等同完整 3.0 生产发行验收。

## 文档阅读与来源目录保持 · 2026-11-13

Studio 与成品阅读器改用完整的 Markdown AST 渲染：整篇正文一次解析，准确章节锚点继续绑定；完整文档保留原文，部分可见文档仅投影准确可读章节并重算行定位。支持中文标点相邻加粗、表格、嵌套列表、引用、脚注、安全 HTML 格式、代码高亮、公式和 Mermaid 图表。Studio 复用既有隔离 PlantUML；成品的 PlantUML 仍保留源码。渲染所需引擎、字体和许可内嵌，原型及密钥隔离继续保留。

文档与知识助手共用渲染器，图片按所选草稿/快照的资料包附件读取，正文未改而图片已更新时也能显示准确版本。HTML 转 Markdown 保留阅读结构，原始上传字节独立保存；有附件的单 HTML 文档保留原始阅读入口。源文件开头的前言进入章节索引，正文不因分段丢失。旧无作用域附件入口仅能读取准确来源的登记附件，不能借相对路径获取原始 ZIP、运行页或其他解析正文。

新增共享 `document_navigation` 投影与不可变资料包目录元数据。已导入手册按原始字节解析声明目录；普通 ZIP 按路径和归档顺序构建树。目录只包含当前可见准确文档，空容器省略；历史快照、资料替换、文件移动和回退都使用对应版本。移动未改正文的文件保存新的路径修订，逻辑身份、人工正文、锁及既有输入权限保留。Studio / 成品以顶部分类和左侧文章、小节树阅读，搜索与引用自动定位，多个资料包互不混合。

## 原样文档插件 · 2026-11-13

HTML 手册和静态站文档包默认使用原始页面，Markdown / TXT 使用标准阅读器。平台正文、章节及向量索引保持独立；新增 `NativeDocument` 描述将当前准确索引映射至获授权的原始包、文章、路径及章节。整包原始成员、当前全部选中章节和附件都必须可读，部分可见时不提供整包入口。HTML 不在后端执行。

原样运行通过可信 Studio 来源登记，HTTP CSP 来自服务端登记的模式与明确 HTTPS 网络范围。原型继续不联网；文档保留自己的脚本、AI、目录和搜索，桥接仅观察位置与处理精确跳转，不拦截原有右键、点击或修改样式。原始字节以 Blob 页面运行，修复 srcdoc 的原生片段链接基址问题；静态站跨页及同页锚点也触发原有 hash 路由。

来源按账号、项目、逻辑包、内容摘要及模式隔离，使用私有持久化 HMAC 密钥派生，同一原始版本的 localStorage / IndexedDB 在刷新与服务重启后可继续使用。平台凭据不进入运行器，用户在原文档中自行配置模型 Key。网络配置只含公开来源，不含 Key，保存后重开运行器应用新策略。未自动复用原文档的 AI 或向量作为平台事实来源。

平台引用检查完整原文与准确索引一致性；不一致时默认标准阅读，并提供明确的来源版入口。资料导入记录原始规范正文摘要，目录以轻量标记识别人工修改及旧来源不确定情况，无文档参数的默认入口同样遵守准确版本。此次不改变既有统一只读成品导出契约，插件原生编辑/外部写入能力不自动进入只读成品。
