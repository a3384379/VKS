# VKS 3.0 首发开发记录

本版依据 [D1 产品与技术方案](VKS_3.0_完整产品与技术方案.md)，从 2.0 基线 `2ec30d9` 升级。工程与试点结果见[验证记录](VERIFICATION.md)。

| 范围 | 使用入口与实现 |
| --- | --- |
| 原样导览 | 含原型的项目提供「原型导览」，可按页面与状态切换。PNG 以原始字节保存，按记录的视口和 DPR 显示。热区独立覆盖，原尺寸、等比适宽和键盘操作共用相同坐标。缺图状态显示目录和已有动作 |
| 资料导入 | 「维护 → 智能接入 → 原型 / 混合资料」可以同批预检 Markdown、VKS 包、原型图及两个受支持的云收费离线 HTML 包。HTML 适配器读取已知的结构化数据并保存原始输入。可跳过有问题的独立资料，所选资料在一个事务入库。任务中心可重开预检报告，草稿变化后可使用原上传对象重新预检 |
| 页面与动作 | 草稿的「维护页面与动作」可添加状态、补录原始 PNG、绘制热区、用数字修正坐标和选择目标状态。移动热区保留动作身份。改变动作名称或移除适用位置会标记受影响的关系 |
| 业务点与文档 | 可新建业务点或复用既有条目，保存说明、适用条件、结果、例外、排序和准确章节证据。支持只用于触发状态、所有状态、移除与恢复。文档反查精确页面、状态和动作，历史快照仍引用原修订。出处失效可单独查看 |
| 流程、检索与导航 | 复用 Journey、文档搜索、知识地图和旧链接。业务流程可绑定同版原型页或动作的准确状态。项目设置支持默认入口、快捷菜单排序及分组。最近位置按账号、项目和版本保存 |
| 版本与资料交换 | 保存快照、克隆草稿并比较原型布局、动作定义、文档、业务点及绑定。已有默认版本时，保存新快照后可单独设置默认版本。可回导知识包携带可见状态原图、准确文档、原图来源和有效业务点绑定 |
| 权限和运维 | Web 与 MCP 共享版本范围、可见性、证据和保存服务。新增两个 MCP 工具读动作说明和写业务点关联。项目设置显示已记录的实例备份与恢复状态，CLI 管理一致归档及恢复 |

离线脚本型原型的画面来自单独采集的 PNG。试点用用户提供的离线原型 HTML 在隔离 Chromium 中生成截图，采集时拦截外部网络。导入与 VKS 导览按资料数据处理，运行时不会重放业务操作。已有静态 HTML 继续使用安全预览。静态资源闭包及保真渲染仍待实现。原环境实时伴读属于 D1 单列的 3.0.x 增量。

## 试用

1. 运行 `make install` 和 `make dev`。已有实例升级步骤见[安装、升级与回退](RELEASE.md)。
2. 创建项目，填写项目标识 `prototype-demo`。用下列命令生成可分享的合成资料包。也可用 `--project` 指定实际项目标识。

   ```sh
   uv run python scripts/build_prototype_demo.py /tmp/vks-prototype-demo.vksbundle.zip --project prototype-demo
   ```

3. 在项目的「维护 → 智能接入」选择「VKS 资料包」，预检并确认导入。打开「原型导览」，选用 `prototype-v1` 草稿。
4. 在列表试用新增收费项、同步月卡套餐、导出，或进入编辑画面后选择违约金设置。编辑需要相应权限。使用「保存快照」固定当前版本。

## 云收费离线试点

手册中 204 份原文摘要全部吻合。原型包识别出 102 条路由、102 个页面、227 条资源记录。8 张已定位原图覆盖四页，其中收费项管理包含列表、新增、编辑、违约金设置和月卡同步确认五种状态。其余 98 页已建目录，画面待补录。同步试点停在确认框。

| 动作 | 准确来源 | 章节起始行 |
| --- | --- | ---: |
| 新增收费项 | 《收费配置到批量出账流程》「4. 主流程」 | 35 |
| 同步月卡套餐 | 《manage 管理中心业务说明》「17.3 停车月卡配置」 | 1301 |
| 违约金设置 | 《账单违约金计算豁免与调整操作手册》「1. 先问客户想改什么，再找对应入口」 | 5 |

试点数据库、源材料和浏览器证据保存在忽略目录。用 `scripts/prepare_charge_pilot.py` 可从两份原始 HTML、本地 PNG 和状态配置重建隔离试点。参数可通过 `--help` 查询。
