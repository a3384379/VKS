## 原手册框架模板

此前的下载框架复用了成品阅读器，带有平台头栏，与用户要求的“原知识手册空白模板”不同。本轮将原手册的独立布局、目录/搜索、Mermaid、AI 问答及文档更新框架抽为 Git 内静态资产。清空业务正文、分类、图片、语料和向量，保留空白阅读引导；下载不包含 Studio 壳、原型或用户凭据。

目录导入支持 MD/Markdown/TXT 与位图；保存保留原始 Markdown（含 CRLF）及图片字节。同路径更新不追加重复文章；只替换图片也可保存并刷新文章显示。无需 Key 即可导入、阅读及下载；向量重建为显式可选操作。原手册的本地 Node 伴随服务不作为模板依赖，设置、历史与文件绑定缓存使用模板自己的命名。重新导回按 `standalone-handbook` 格式保存准确原件与知识清单，原样导出沿用手册布局，并移除更新、原 AI 与作者数据入口，外层只读助手负责问答。旧模板的导入和安全检查保留兼容。

来源脚本只作为已审查的框架静态代码提取；后端导入只解析 inert JSON，校验压缩包长度/SHA、路径、数量与图片格式，不执行材料指令或脚本。新增资产保留供应商许可证注释，未携带原手册正文和私有向量。原始文件不修改，`docs/design/` 不修改。
