# AI 助手独立浏览器窗口

平台与单文件成品的文档助手、原型助手均增加“弹出独立窗口”。点击标题栏的 ↗，可以把助手拖到另一块屏幕；独立窗口顶部的“收回页面”恢复原来的页面内布局。页面内不再保留占位侧栏，正文恢复阅读宽度。当前工作区复用同一个独立窗口，再次点击助手入口聚焦该窗口。

独立窗口使用浏览器自身的移动、缩放与关闭操作；位置和尺寸按工作区或导出快照在本机记忆。浏览器决定窗口外观和最终位置，本功能不请求屏幕枚举或跨屏自动定位权限。页面内原有的浮动、侧边及展开布局继续可用。

## 置顶小窗与浏览器地址栏（2026-11-17）

支持 `documentPictureInPicture.requestWindow()` 的浏览器优先使用文档画中画窗口，替代带 `about:blank` 地址栏的普通弹窗；它可承载完整输入、Markdown、引用预览与图表。该窗口由浏览器置顶，位置由浏览器和用户拖动决定；主页面关闭或刷新时会自动关闭。浏览器仍保留自己的原生窗口标识和控制区。没有该接口或请求被拒绝时，尝试保留原来的普通独立窗口。

打开改为异步，并合并同一助手进行中的开窗请求；切换项目、收回或主页面离开会使迟到结果失效并关闭空窗。样式复制、两种助手视图切换、在途请求和草稿保留共用既有实现。没有尝试通过 `location=no` 或隐藏安全控件伪装普通弹窗。

依据：[Chrome 文档画中画](https://developer.chrome.com/docs/web-platform/document-picture-in-picture/)、[window.open 的浏览器界面边界](https://developer.mozilla.org/en-US/docs/Web/API/Window/open)。

## 会话与生命周期

请求、凭据、检索及操作服务仍由主页面持有。打开或收回窗口不重复请求模型、不建立另一套向量索引，也不更改输出上限。原型对话状态留在宿主；可信文档助手在切换窗口时迁移历史、草稿、范围和检索方式，并接续主页面缓存的在途文字。完整回答继续按原契约验证和保存，未完成输出不作为正式历史。

主页面的当前文档与原型目标更新同步到独立窗口；选中文字仅在右键菜单主动解释时传入，不抢占未发送的草稿。问答正文的数字引用在当前助手窗口预览 Markdown 原文，再由“打开文档原文”导航主页面。独立窗口的浏览器关闭按钮与“收回页面”均恢复页面内助手。即使浏览器关闭跳过卸载事件，也通过宿主持有的最新快照恢复草稿和已完成回答。

普通独立窗口在主页面关闭或刷新后明确显示断开状态；置顶小窗随主页面关闭。普通独立窗口保留已显示内容并停止输入和操作，提供重新打开主页面的链接。旧视图停止自动写历史，避免随后关闭它时覆盖新主页面的会话。刷新后不宣称旧请求仍能独立完成；如需脱离主页面继续运行，需要另行设计持久化会话与任务。

浏览器拦截弹窗时，原助手和草稿保留，页面显示允许弹窗后重试的提示。材料运行区不获得宿主凭据；新窗口只承载平台自己的可信助手视图和样式，不复制或执行导入材料中的脚本。

## 原文预览、输入与记录修复

原型问答的 `[1]` 等编号和折叠依据标题现在打开同窗口原文预览，代码中的编号保持原样；预览正文复用完整 Markdown 渲染。按 Escape 关闭预览后继续当前回答。导出和平台均适用。

平台原型问答按账号、项目、版本、原型目标及资料指纹在本机保存最近 20 轮和草稿；导出按项目与固定快照保存最近 20 轮和草稿。重新进入或刷新恢复内容，不重发请求。未完成请求仅恢复待提问文字，已明确停止的部分回答保留未完成标记。清空问答同步清空当前记录；浏览器存储不可用或空间不足时显示保存失败提示。记录不包含连接凭据，不同步到其他浏览器；文档助手原有的历史会话与保存目录功能保留。

输入区在助手高度的约 18% 内调整，并设最小和最大高度；发送按钮位于右侧，快捷键说明放入悬停提示。保留 Enter 发送、Shift+Enter 换行和中文输入法组合键保护。右键菜单统一左对齐，图标使用固定列。

两种助手共用 `packages/assistant-runtime/src/composer.css` 的输入区外框、焦点、文字区、底部操作栏和发送按钮。构建将同一份样式复制到 Reader 资产，供平台、导出及可信文档 iframe 使用；原型的清空与记录导出也位于底部操作栏。文档的历史会话功能和原型的三个业务页签仍按各自职责保留。独立窗口复制主页面已经加载的可信 CSS 规则，并将相对资源 URL 固定到原样式地址，避免新窗口重新加载样式失败而丢失排版。

独立窗口的图表观察器、隔离渲染 iframe 和超时计时使用实际承载视图的窗口；渲染响应仍校验来源窗口、opaque origin 和每个 iframe 的随机标识。图表引擎入口只接受应用来源及本帧随机标识，保留原沙箱、网络限制和 SVG 过滤。页面内与独立窗口使用相同源码渲染。原样文档阅读恢复平台文档助手入口；选中文字不显示浮动入口，仅右键显示“解释选中文字”菜单。

## 定向验证

新增浏览器场景覆盖平台文档助手的 Responses / Chat Completions 本地 SSE 流中切换、草稿保留、关闭回收、主页面刷新后的断开与历史保护；平台原型助手覆盖弹窗拦截、窗口复用、Enter 发送与引用导航；导出覆盖同一连接配置下两种助手切换、问答、原文定位及收回。

另回归已有文档助手、原型问答、流式展示、导出及共享窗口几何，并完成 Studio 构建。证据位于忽略目录 `.vks/assistant-detached-20261116/`。这些是独立 Chromium 与本地合成服务验证，不等同真实模型质量或物理双屏验收；没有调用付费模型、重跑暂停的真实性能任务或执行全量 `make check`。原始设计交付件不改动。
