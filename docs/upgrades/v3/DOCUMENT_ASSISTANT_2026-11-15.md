# 文档助手与原型助手分离

按用户本轮要求，平台及只读成品的文档助手复用仓库内保留的原知识手册界面与问答展示、历史会话、推荐追问、复制、记录导出、选中文字和展开阅读能力。文档界面不显示关联文档、AI 讲解页签。原型继续使用现有知识助手，并增加复制、重新回答和记录导出。

复用的是仓库自带的可信框架资产，不执行导入材料中的助手脚本。独立框架的模型请求与建库逻辑由宿主接管，使用平台当前权限与所选版本的同一套向量和关键词检索。导出携带该快照的平台向量片段，文档助手不另建或导入另一套索引。原始字节、章节身份及已有结果不重写。

平台两种助手使用项目 AI 设置中的同一连接、服务端密钥与输出上限；文档助手窗口不接收密钥。导出文件中的两种助手使用同一处连接设置，默认 Key 仅在内存，用户可明确选择保存到本机并随时“清除并忘记 Key”。本机记忆按项目和导出快照隔离，恢复后仍经过接口检查。发布者的凭据和接收者的本机配置不写入 HTML。

统一设置保留最大输出 tokens 与逐字/更快/直接显示的选项。当前平台 8000 上限未修改；导出默认 8000，可调整。两种助手均支持真实增量输出，显示速度只影响已收到的正文；引用与正式回答在完整验证后确认。中断与错误内容不进入后续有效对话历史。

问答不再沿用关联任务的 650 字片段和 3 章引用限制：保留更完整上下文，问答最多允许 9 个准确章节引用，按输入预算均衡收缩证据，保留总预算保护。关联与讲解契约独立。提示按问题提供流程、比较、公式示例或排查顺序，区分事实、推断、建议与未知项，并返回具体追问方向。这是实现调整，不等同真实模型质量验收或整体提速结论。

“全部知识”与“当前文章”分离检索范围和当前文档身份；范围在检索 Top K 之前过滤。当前文档身份仍用于明确的修改/导出指令。仅查原文不调用嵌入或回答模型。平台文档编辑与导出继续走既有应用服务、版本和幂等保护，历史会话与回执不因修改生成的新修订而清空。

导出原样文档的“标准阅读”按钮移除；搜索、打印、阅读样式和准确引用定位保留。来源不完整时仍有内部阅读回退。

定向证据保存在 `.vks/document-ai-20261115/`。验证使用合成材料、本地 SSE 服务和独立 Chromium；未调用真实付费模型、未重跑已暂停的真实资料性能任务，未运行全量 `make check`。`docs/design/` 未改动。

保留原手册“问答设置”中的全部知识/当前文章、向量＋关键词/关键词＋AI/仅查原文、历史会话切换和保存目录。历史默认自动保存在浏览器；本地目录保存使用原框架的目录授权与记录格式。模型输出上限和显示偏好独立于 Key 记忆，清除 Key 不清除这些偏好。

2026-11-16 按用户补充去除“平台知识索引”和“统一连接设置”说明卡片，并隐藏没有独立操作的“知识索引”页签。保留简洁的模型连接设置入口、实际聊天设置、历史会话和保存目录；检索仍共用平台索引。

同日将问答范围、检索方式及历史会话改为紧凑行，缩小回答显示设置与欢迎图标，图标和欢迎标题同行。文档助手提供“浮动小窗 / 侧边展开”、展开阅读、恢复默认位置与大小。拖动与八向缩放作用于宿主窗口，侧边模式可拖动左边缘调整宽度；布局、位置与大小按项目和所选版本在本机记忆，收起重开不丢失。窄屏及视口变化时限制在可见区域。

文档页移除多套阅读模式下拉，沿用项目已有阅读样式。原 HTML 仅保留“查看原文 / 返回文档”入口，内部格式回退及旧版本呈现记录仍兼容；不改写资料或已有选择。导出原样文档不再显示“标准阅读”按钮。

本轮定向检查：文档/会话浏览器 8 项、阅读与后台刷新 2 项、原样 Studio 与导出兼容 2 项、共享窗口几何 1 项通过，Studio 构建完成；未跑全量测试。另用已有真实导出快照的 204 篇文档、6157 个向量片段做离线原文查询、引用定位和宿主窗口拖动/缩放/重开检查，无外部请求；该文件为旧快照体验副本，不代表当前项目完整导出。

引用预览补修：原手册的引用子窗口原先直接用纯文本显示章节，Markdown 标题、表格和代码标记因此原样出现。现复用回答正文的 Markdown 解析和清理流程，表格保持横向滚动，解析失败时保留原文回退；只改变显示，不改原文、引用身份及会话记录。平台和导出两项定向浏览器检查覆盖标题、表格、嵌套列表、行内/围栏代码与来源脚本不执行，未运行全量测试或调用真实模型。

问答展示补充：原型提问气泡右侧对齐，回答下的章节依据默认折叠；展开后使用 Markdown 显示准确章节正文。文档正文的 `[1]` 等编号按本轮引用顺序成为原文预览按钮，移除段后重复的 S1–S9 按钮；内部来源 ID、历史记录和证据映射保留，代码、链接中的编号不转换。折叠依据改为 Markdown 正文，历史恢复沿用同一展示。平台与导出的原型问答均支持 Enter 发送、Shift+Enter 换行；输入法组合及 keyCode 229 的确认回车不发送。

文档依据正文在首次展开时解析，后续开合复用节点；展开时暂停自动跟随并保留阅读位置。定向浏览器覆盖平台/导出的四项文档场景及两项原型场景，另通过 Studio 构建；真实“资料清单”的折叠依据和原文预览均显示 Markdown 表格。本轮没有执行全量测试或真实模型调用。

选中文字交互修正：平台与导出的准确正文、原样文档均先显示“解释选中文字”按钮，普通选择与复制不展开助手、不恢复独立窗口，也不移动输入焦点。点击按钮后才打开文档问答、带入所选内容并填入解释问题，仍需主动发送。收起助手后的草稿保留；迁移窗口时不重放解释动作或覆盖后续草稿。清除选择、切换文章或离开文档时收起待解释入口。
