# VKS 3.0 验证记录

日期为 2026-11-11。工程回归、云收费离线原型试用与真实业务验收分别记录。

| 检查 | 实测结果 |
| --- | --- |
| 全量 `make check` | Python 769 项通过、16 项按环境条件跳过。前端 59 项通过，TypeScript 和 Vite 构建成功 |
| 原型专项 | 导入预检摘要错配、取消、幂等重放、陈旧草稿冲突、坏坐标、画面缺口及原图权限。原文反查、移动热区、业务点保存和历史快照回读均有用例 |
| 维护者浏览器闭环 | 切换状态时未保存热区不串到其他状态。拖绘保存后可在画布点击新控件，保存业务点后可从原文章节反查到同一动作及触发状态 |
| 云收费隔离接入 | 真实离线资料的 204 份 Markdown 与 102 条路由全部识别。102 页中四页有画面。所有八张原图以原字节读取 |
| 原型浏览器对照 | 1440 × 900、DPR 1、热区关闭时，四页八个状态的画布与隔离 Chromium 的离线原型采集图 8/8 像素相同。VKS 试用期间记录到的外部请求为 0 |
| 原文和流程 | 浏览器中三条动作 3/3 命中指定原文，新增原文往返恢复同一画面，导出动作显示无说明，四个流程步骤均打开准确页面 |
| 本机动作说明延时 | 在有 204 份手册的隔离项目中轮询新增、月卡和违约金，排除每条第一次请求后统计 90 次本机 HTTP 请求，热读 p95 为 5.23 ms。服务方法热读 p95 为 4.61 ms |
| MCP | 官方 HTTP SDK 通过草稿写入、幂等重放、同版读取与撤权。官方 stdio SDK 通过草稿写入、精确快照读取与撤权。V1/V2 合约及既有工具继续通过回归 |
| 备份与恢复 | 云收费隔离实例恢复后 8/8 原图摘要一致，准确业务点及章节可读取。可回导包专项验证原图字节、逻辑实体和关系证据 |
| 出处与权限 | 修改文档后新草稿的出处进入待核对，已保存快照保留旧章节修订。受限动作从页面热区和检索结果中消失 |
| 升级与回退 | 用 2.0 基线生成的 SQLite 快照升级至 3.0 后，旧快照摘要及文档修订一致。回退到预升级备份并使用旧程序读取，也得到相同摘要与修订 |
| PostgreSQL | PostgreSQL 17.11 独立数据库运行 Alembic 到 `k04dba683021`，现有 PostgreSQL 6 项专项通过。另在独立库通过 3.0 导入、业务点、默认入口及冻结原图回读 |
| 契约与文件完整性 | 冻结 V2、V3 OpenAPI 与 MCP Schema，验证生成产物及真实 SDK。原始 `docs/design/` 44 份文件摘要校验通过 |
