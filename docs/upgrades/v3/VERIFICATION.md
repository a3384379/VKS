## 3.0.0-rc.1 多轮复审

复审基线为 `850c442`。第一轮检查导入与回导、版本与权限、Web 与 MCP。全量回归复现了成员降权后设置页丢失当前模块面板的问题。修复后复跑通过 800 项 Python 测试及 59 项前端测试。随后复审对比报告、导出来源、刷新后的导入收据，以及新版手册对未修改文档的影响，并增补相应用例。

最终 `make check` 为 Python 809 项通过、16 项按环境条件跳过，前端 59 项通过，TypeScript 与 Vite 构建成功。`make contracts`、锁文件检查、依赖一致性和 `npm audit --audit-level=high` 通过。原始 `docs/design/` 文件与基线一致。

从两份离线 HTML 和原图重新接入试点后，复跑三条动作和四步流程。本机快照 HTTP 热读 90 次，p95 为 12.55 ms。

压力集合使用 Apple M4、16 GiB、macOS 26.6.2 上的隔离 SQLite 实例，通过导入任务入库 1,201 份合成文档，草稿共 16,814 个选中实体。三条动作轮询，先预热，每组 120 次本机 HTTP 请求。4 路并发时，草稿 p95 从 369.78 ms 降至 39.33 ms，冻结快照为 31.05 ms。与回归测试并行的复测分别为 60.15 ms 与 66.53 ms。另修复了这一规模下工作区超出 SQLite 查询参数上限的问题。

静态 HTML 保真渲染所需的本地样式、字体和图片闭包仍待实现，当前可使用原图导览与既有安全静态预览。真实收费运行结果、五人次独立试用和生产发行仍待验收。
