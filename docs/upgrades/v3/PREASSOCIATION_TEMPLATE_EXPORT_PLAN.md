# 预关联、手册模板与导出阅读方式

2026-11-14，实施基线 `bb7d401`。本文件是本轮开发方案，完成情况以随后验证记录为准；原始 `docs/design/` 不变。

## 交付范围

1. 关联管理增加全量、补齐、变更项预关联。保存后台任务、准确资料组合、逐项结果及恢复点；模块和控件分别处理，重复表格操作共享一次模型核对。保留人工说明、用户移除和现有点击补查。静态扫描、动态未覆盖、依据不足与实际关联覆盖率分别展示。
2. 提取无业务内容的手册框架。模板源码与版本进入 Git，项目正文、向量、个人配置与密钥留在项目私有存储。模板使用当前授权正文和目录，AI/文档更新回调复用平台流程。
3. 文档阅读方式作为草稿配置进入准确快照，克隆和版本恢复保留。已有项目默认延续现有行为，可选择标准、手册模板或原样阅读。
4. 单文件 HTML 导出增加项目阅读方式/导入原文档选项。原样整包必须满足完整版本与权限闭包；不能安全适配的原始交互明确回退标准阅读。成品关闭内容更新/编辑，个人 AI 设置继续可用；不包含发布者凭据。
5. 项目与导出共享窗口手势、尺寸约束、模型精简等交互逻辑。导出复用 Markdown、关联正文优先、自动讲解及目标隔离；导出没有关联编辑入口。
6. 资料管理提供可选的空白 HTML 模板下载，文档区不放模板下载入口。用户可在本地导入 Markdown 和图片、整理目录、保存可继续编辑的 HTML，再导回平台；普通文档仍可直接导入。通过显式惰性 JSON 数据包抽取正文和资源，沿用导入、版本和建库服务，不执行作者文件的脚本；本地个人 AI Key 与问答历史不进入保存文件。
7. 扫描与 AI 关联同时推进。浏览器默认使用 3 个独立 Runtime（可选 1–4 个）采集页面，每页结果落库即形成不可变的后台关联子任务，后续扫描继续进行。扫描并发与模型并发分别调度；不向执行中的模型任务追加会丢失的目标，也不占用后台执行器等待浏览器。整个扫描任务及逐页、逐项状态持久化，切换工作台页签不卸载扫描器；刷新或连接中断后从原任务继续。暂停仅停止采集，停止任务同时取消该任务已排队的关联。

## 数据与权限

- 新文档展示配置表按草稿保存；设置写入同时检查 `If-Match`、知识编辑权限和幂等键。冻结版本从清单读取配置，不读取会变化的项目偏好。
- 原始资料字节、不可变修订、引用与向量事实不因换模板而改变。模板升级与文档更新分别记录。
- 批量任务以当前账号、项目、原型与文档组合为范围；执行、续跑、写入、下载均重新验证权限和版本。停止旧资料组合任务，不让迟到结果进入新资料。
- 普通模型请求不重新引入每日 Token 或费用配额。任务并发和取消用于调度，不构成用户用量限制。
- 并行模型保存关联导致草稿计数变化时，扫描仍绑定原始资料组合及准确原型字节；资料替换、权限收紧、任务接管和取消继续拦截迟到写入。页面采集失败和 AI 失败分别保存，成功项不因重试而重复提交。

## 验收

- 普通 MD 项目选择模板，分类/目录/搜索/正文/图表/上下篇可用；空项目不含云收费样例。模板更新入口进入平台资料管理，更新后准确正文和 RAG 同步。
- 下载模板为空，需登录但不读取项目资料。本地整理后保存、重开及重新导入应保留正文、图片和目录；同路径更新不创建多份文档，显式阅读偏好不被覆盖。只读成品不包含作者编辑入口或作者运行时钩子。
- 未点击控件前可启动批量预关联，已有人工/排除项保留；重复操作减少模型调用；停止、继续、版本变动、撤权、资料不足均有实测断言。
- 在刻意延迟的页面上核对确有 3 个采集并行、首批关联在末页采集前完成；刷新、跨页签、单页失败、取消及迟到响应均不丢失已保存结果，不把失败或尚未扫描的页面计为已采集。
- 原样文档导出保留可兼容的布局与准确定位；整包部分授权、正文偏离原件和无法保证只读时有明确结果，不能偷偷导出被隐藏内容。
- 导出助手连续拖动/缩放、模型筛选、Markdown、自动讲解和切换目标更新通过独立浏览器；离线文档可读、联网 AI 由接收者填写密钥。
- 最终运行 `make check`、契约生成与官方 MCP SDK、SQLite 升降级，记录真实模型/真实业务/生产验收边界。
