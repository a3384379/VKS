# 单文件只读成品库

Studio「原型与文档」提供「导出当前成品库」。导出先保存独立快照，当前工作区继续可编辑；也可以在完整版本列表中导出指定旧版。任务完成后下载一个 `.html` 文件。

成品由平台统一生成，不使用导入手册自带的 AI、向量库或阅读器。普通 Markdown 在平台内按准确章节切分，建立真实嵌入索引；导出会补齐当前所选章节缺少的向量。请先在项目 AI 设置中配置回答与嵌入连接，启用 RAG，并允许使用相关资料。建库使用平台配置的服务与预算；未配置或索引不完整会明确报错，不生成假向量。只有文档、没有原型的项目也支持自动建库和导出。

HTML 包含所选快照的可见原型、平台章节、有效关联与讲解、准确引用、向量片段和独立阅读器。原型在浏览器隔离区演示，文档安全渲染为阅读页面。普通文档 ZIP 的相对栅格图片可以一起打包；无法获取的图片给出缺失提示。系统不在服务器上执行导入材料。

## 使用成品

- 使用新版 Chrome、Edge、Firefox 或 Safari 直接打开 HTML。离线可阅读文档、搜索章节、浏览原型、查看已有讲解，并在文档与原型关联之间跳转。阅读不需要 VKS 服务、账号、CDN 或浏览器缓存。
- 点击右下角「知识助手」打开相关知识、AI 问答与连接设置。在原型上右键可以查看当前控件知识；「模块知识」显示当前页面的关联。没有已保存关联时，本地检索即时显示可能相关的原文，不冒充已核对的 AI 关系。
- 联网问答由使用者填写自己的服务地址、协议、模型和 API Key。可获取模型列表后下拉选择，也可输入模型 ID。支持 Responses 与 OpenAI 兼容 Chat Completions。密钥只放在当前页面内存，刷新或关闭后清除；不写入 HTML、localStorage 或 IndexedDB。
- 可选择联网嵌入检索，使用与导出向量相同的模型和维度。不可用时明确退回本地关键词检索。新的 AI 回答需要网络和可用模型，不包含离线语言模型权重。
- 回答以流式文字显示，引用可点回原文章节；取消、断流、额度不足或模型不兼容都会显示状态，不把未完成回答标成成功。

浏览器直接调用用户选择的模型服务，服务必须支持浏览器跨域请求；本地文件通常使用 `null` 来源。不同供应商或代理的兼容性取决于其 CORS 设置。只对用户确认的地址发送密钥和检索到的章节，原型运行区不接收密钥。

## 固定范围与只读边界

成品没有资料导入、修改、版本维护或知识写入接口。原型中的表单仅在本次演示内运行，不连接业务服务。只读指产品不提供知识编辑能力，HTML 文件本身仍可以复制或由持有者用其他工具修改。

导出按项目、快照及当前权限投影。原型包检查完整原始成员；文档、引用和向量使用相同准确章节范围。导出任务在网络调用前后复核权限、配置、取消状态和版本，下载再次检查原型字节、原始成员、章节与出处权限。只导出所需向量，不复制实例向量数据库、其他项目、查询缓存、调用记录、模型连接或任何发布者凭据。发给其他人后，离线副本不随平台撤权自动失效。

静态站 ZIP 应包含全部本地资源。外部 CDN、服务器业务接口、动态远程模块和原始手册的专有功能不属于离线运行保证；平台的文档阅读、检索、关联与助手独立提供。当前验证范围见 [验证记录](VERIFICATION.md)。

本机也可通过同一快照与任务服务生成文件：

```sh
uv run python scripts/export_readonly_library.py \
  --data-dir .vks/studio-preview/data \
  --project-id <项目ID> --include-source \
  --output /目标目录/项目成品库.html
```

工具使用本机实例所有者权限；默认不包含源码，可按需指定 `--include-source`。指定 `--release-id` 导出既有快照，否则保存当前工作区的独立导出快照。目标文件存在时拒绝覆盖。
