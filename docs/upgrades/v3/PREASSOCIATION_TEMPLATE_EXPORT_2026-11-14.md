# 预关联、模板与原样导出修复记录

开发基线 `bb7d401`，2026-11-14 开始。本记录和 [实施方案](PREASSOCIATION_TEMPLATE_EXPORT_PLAN.md)描述本轮新增能力；实际验收范围以最终验证记录为准，未改变 `docs/design/`。

## 持久预关联与并行流水线

原实现的两个等待阶段分别是浏览器逐页挂载/采集，以及全部页面完成后才开始 AI 关联。前者随慢页累加，后者让用户很晚才能看到首批结果。新实现把采集与关联分成可重试的两个阶段。

- `PrototypeScanRun` 保存账号、项目、资料组合、准确原型摘要、声明页面计划、已尝试/成功/失败页、客户端租约及运行状态。Runtime 由全局工作台协调器托管，切换工作台页签不再卸载。刷新需要明确继续，保留成功页面；单页错误不删除整轮进度。
- 默认 3 个 Runtime 并行，可调 1–4 个；每个有独立通道、页面导航与临时存储。共享唯一待扫描队列，页面保存后才算已采集；乱序回包以服务端版本为准，旧任务、旧客户端和停止后的结果不能写入。
- 每页成功保存后形成不可变的后台关联子任务。子任务的目标不会在执行中追加，避免执行快照遗漏后来采集的页面。主扫描任务聚合 AI 状态，重复目标入队幂等；重复表格操作共享一次推理，不跨不同业务页面错误合并。
- 本地为这些子任务提供 3 个有界后台执行槽，普通任务保持既有调度。执行前和提交前核对当前身份、权限、资料组合、任务租约、取消、人工说明及用户排除状态。暂停只停止采集，停止整个任务取消其关联队列。
- AI 保存绑定会改变草稿计数，但不改变原型和正文的准确组合；扫描使用任务起始版本及资料组合核对，避免自身关联更新误伤后续页面。更换资料、冻结、切换工作区或撤权继续拦截旧结果。
- 新增三项持久表的迁移分别保存文档呈现、浏览器逐页库存与扫描任务；流水线目标另有按任务/目标唯一的记录。数据库事务不包含模型网络等待。

默认页采集不点击业务按钮、不打开条件弹窗，也不声称发现尚未挂载的动态控件。不可读 frame、未挂载、超量及失败保持明确缺口。导入解析只读取资料数据，后端不执行原包脚本。

真实数据库的私有一致副本中，269 个成功采集页面、2,894 个控件的旧任务恢复约 **0.685 秒**返回；记录 3,163 个准确目标，只先创建 8 个操作组任务，其余 3,150 项分批入队。未扫描的模块没有被补造为已采集。测试禁用了所有网络连接，没有模型调用。早期同步恢复在大事务写入后另开读连接，会发生 SQLite 自锁；改为同事务读取库存和任务状态，并用强制小页缓存、1 MiB 未提交写入重现并验证修复。状态轮询改为 SQL 聚合计数，200 个各带 64 KiB 工作内容的测试不加载目标或模型工作对象。

审计中发现不同 `InteractiveAssistant` 实例的建库锁互不共享，会在 3 个子任务冷启动时重复计算同批嵌入。锁改为共享，并为向量存储增加带心跳的短事务租约；网络等待不占主业务事务，入锁与保存前重新核对权限、配置和取消，持有者失效后可恢复。

最后交叉检查修复后台绑定保存清空问答的问题。绑定保存会增加草稿计数，原聊天身份使用该计数，因而误取消在途问题并清空草稿和历史。现在聊天与引用绑定权限过滤后的准确文档、选中章节和原型修订指纹；只保存关联时会话不变，真实替换、取消选择或收紧可读来源时旧上下文失效。来源指纹通过薄投影计算，不读取章节正文。此项在全量回归之后另补文档、问答、SDK、来源权限及实际并发浏览器专项，并重新构建 Studio。

## 可选手册框架与本地整理

`packages/handbook-template/` 保存无业务内容的版本化框架，提供分类、目录、搜索、正文、图表、上下篇、打印和 AI 入口。平台使用当前授权的准确文档和章节；文档-only 项目也可问答。切换阅读方式不复制或改写原件，阅读设置随完整版本保存与恢复。

模板下载只在资料管理提供，普通文档仍可直接导入。下载的是空白、可编辑 HTML，用户可本地导入 MD/TXT、图片或目录，整理后保存并重开，再导入平台。保存文件从固定干净骨架重建，不保存当前 DOM、个人 Key 或问答历史。

平台只抽取显式的惰性模板 JSON 信封，严格核对版本、字段、路径、数量、字节、图片编码及重复项；原 HTML 作为原件保留，不执行作者脚本。重新导入沿用资料服务的逻辑身份、不可变修订与准确章节映射。相对资源引用采用相同 Unicode 规范；路径越界、跨项目资源、坏图片、伪造信封与不支持的格式拒绝。只读导出没有作者编辑入口或作者运行时钩子。

## 项目呈现与原样导出

资料管理可选择项目阅读方式或导入原文档。原样呈现仅在完整、当前获授权且与原件相符的来源闭包下启用；已修改正文、部分授权、未知活动格式或无法安全适配时明确回退标准阅读。当前适配已知知识手册与静态站点，不宣称任意 HTML 应用均能无损转换。

已知手册保留原布局、目录、准确章节、上下篇等阅读元素，移除内容更新、作者导出和原有凭据入口。修复原手册压缩编解码脚本在移除旧导出模板后访问空节点的问题，并修复重复快速定位的迟到滚动及空工具条占位。原始字节未修改，适配结果单独生成。投影缓存仅保存按摘要绑定的来源事实，每次生成和下载仍重新验证授权与准确版本。

导出与项目助手复用窗口手势：可拖动图标、拖动面板、连续调整尺寸并约束视口；保留原型输入。导出支持 Markdown、图表、原文优先、紧凑模型列表、目标切换与自动讲解，去掉关联编辑。联网问答由使用者填写个人密钥，只保存在页面内存中。

## 本机观测与边界

同一真实资料的原样导出投影冷读，从早期观测约 16.69 秒降到 4.88 秒，热读约 2.04 秒；包含完整向量的准备约 10.84 秒、最终核对约 2.29 秒。这是本机对应样本阶段耗时，不等于端到端模型回答、跨机器负载或 p95。

修正版实际 HTML 文件约 59.7 MB，在隔离 Chromium `file://` 会话打开 242 篇文档及一个原手册来源包，进入原样文档并打开助手约 3.17 秒，页面错误为 0、外部 HTTP 请求为 0。个人 Key 为空；没有作者运行时。空白下载模板约 6.52 MB，文档与图片均为 0，离线打开无页面错误。它们验证对应固定快照和产物，不表示整套收费业务、全部控件关联质量或生产发行已经验收。

开发期间用户预览曾加载新前端而旧 API 尚未更新，出现扫描入口 404、`allow_partial` 额外字段 422。预览改为固定构建模式，最终更新按同一版本同时部署 API 与前端；保留一致数据库备份和原扫描检查点。历史早期续跑删除失败计数的兼容恢复仅采纳同账号、同资料/原型、计划内且任务开始后的失败观测，绝不补造成功采集或直接调用模型。

最终测试数量、并发速度对照、迁移与部署结果追加在 [验证记录](VERIFICATION.md)。未配置的 PostgreSQL 环境、任意原始站点、所有真实模型供应商及真实业务验收不得计作已通过。
