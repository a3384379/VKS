## 重点修正

- 原型元素与文档章节使用稳定逻辑键，显式绑定优先；不是每次重新进行模糊匹配。
- documents 边统一为主体实体到文档章节，反向浏览使用入边查询。
- 修订摘要包含来源、定位和 metadata，避免正文未变时误复用旧定位。
- 不合并内容相同但来源 revision 不同的版本记录。
- 状态分支只用于讲解，录制执行仍为有限线性步骤；观察、模拟、声明分开标注。
- MCP 任务结束与人工审核分开；普通 AI 令牌不直接批准或发布。
- 总览指标具有明确分母；MCP UI 工具名称与正式契约一致。

## 检查边界

- 当前环境未安装专用 OpenAPI 3.1 / JSON Schema 2020-12 元规范验证器。因此只声明解析、引用及针对性用例检查通过，不声明完整标准兼容认证。
- Mermaid 已检查源文档一致性，技术图提供可读的 SVG/PNG；没有声称完成所有 Mermaid 阅读器的兼容测试。
- 未连接用户真实仓库，未编译或启动业务项目，未执行 Maven，未验证任何真实开票接口。
- UI 是高保真概念图，包含合成数据和示例代码，不可当作已上线产品或实测业务行为。
- 性能、收益与排期属于设计目标或估计，需在 PoC、真实试点和独立验收中验证。

正式实施时，应将第 23 章的验收矩阵转为自动化/人工用例，并在 CI 增加标准契约验证、隔离与权限测试、真实支持范围 fixture 和恢复演练。
